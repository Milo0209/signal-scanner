# signal-scanner

A 24/7 system that scans live market data, scores opportunities from 0 to 100 and alerts me in real time. Strategy variants compete against each other in paper trading under a champion/challenger scheme, and the best one is promoted automatically.

## Highlights
- Honest paper-trading prices and shadow books per strategy variant
- Automatic promotion of the best-performing variant
- Daily ledger analysis and real-time alerts to my phone

## Status
Running in paper mode only – no live trading.
